# 修复及运行说明

S1/E1/I1/I2/T1/T2/T3/T4/R1/E2 已按 threats.md 实现。回归命令：

```sh
node qiuzhao-mp/security/isolation.test.cjs
```

模拟数据库和网络只服务测试，不进入云部署代码。v2 备份包含本人手动公司和方案条件；恢复手动公司创建新的 owner 绑定和 ID，再映射投递记录；AI 推荐结果应重新生成。旧共享 preps 缓存不再读取，历史无 owner 的条目暂保留，不删除其他账号可能用到的资料。

管理员专项扫描需在 api 环境变量设置 `ADMIN_OPENIDS`（逗号分隔的管理员微信 OPENID）。留空时普通账号和无身份的集中扫描调用都会拒绝。既有 timer 调用保持工作，无需管理员变量。不要把管理员身份或密钥写入前端。

已核实旧来源的专项队列使用 origEvidenceV/ncssEvidenceV=2 分批重审；网页无法读取、年份或企业不匹配不升级核实，核实率可能降低。来源读取失败会延后一天重试，不清空已有学历资料。

I3：已在真实 cloud1 控制台逐一确认 companies/apps/profiles/meta/reminders/preps 六集合均为“所有用户不可读写”。后台云函数负责读写，没有修改这些权限。

D1：需在腾讯云控制台核对资源限额和告警；本轮未增加搜索或 AI 的预算上限。依赖更新、隐私指引和大规模导入超时仍需后续单独验收。
